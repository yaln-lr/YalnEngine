# YalnEngine 灯光使用说明

> 适用：viewer 示例（main.cpp）与任何基于 `IYalnScene` 的应用
> 设计细节见《灯光系统设计说明》（docs/灯光系统设计说明.md）

---

## 1. 快速上手（三步）

```cpp
#include "yalnlight.h"   // 灯光系统头文件

// ① 环境光（决定暗面底色，建议最先加）
auto ambient = std::make_unique<YalnAmbientLight>();
ambient->setColor(glm::vec3(0.58f, 0.65f, 0.78f));   // 偏冷天光
ambient->setIntensity(0.55f);
scene.addLight(std::move(ambient));

// ② 太阳（平行光：direction 是"光的传播方向"）
auto sun = std::make_unique<YalnDirectionalLight>();
sun->setDirection(glm::normalize(glm::vec3(-0.45f, -0.35f, -0.9f)));
sun->setColor(glm::vec3(1.0f, 0.96f, 0.88f));
sun->setIntensity(0.9f);
scene.addLight(std::move(sun));

// ③ 路灯（点光：位置 + 作用半径）
auto lamp = std::make_unique<YalnPointLight>();
lamp->setPosition(glm::vec3(0.0f, 2.4f, 1.62f));
lamp->setRange(8.0f);
lamp->setIntensity(1.3f);
scene.addLight(std::move(lamp));
```

**不加任何灯也能跑**：渲染器有环境光兜底 `(0.25, 0.25, 0.28)`，旧场景不会全黑。

## 2. 四类光源 API 一览

### 2.1 YalnAmbientLight —— 环境光

全场统一底色，无方向、无衰减。

| 方法 | 说明 |
|---|---|
| `setColor(vec3)` | 光色（建议偏冷/偏暗，作为"天空散射"色） |
| `setIntensity(float)` | 强度，典型 0.4~0.7 |

> 环境光最多生效 1 盏：多次添加时**后添加的覆盖先前的**。

### 2.2 YalnDirectionalLight —— 平行光（太阳/月光）

无限远方向光，无位置、无衰减，全场景所有面统一按方向计算。

| 方法 | 说明 |
|---|---|
| `setDirection(vec3)` | **光的传播方向**（自动归一化，零向量兜底 -Z） |
| `setColor` / `setIntensity` | 强度典型 0.8~1.2 |

调参直觉：想让受光面朝哪个方向，就把方向向量设为从那个方向指向场景内部。
例：太阳在东南上空 → `direction = normalize((-0.45, -0.35, -0.9))`。

### 2.3 YalnPointLight —— 点光源（路灯/火把）

| 方法 | 说明 |
|---|---|
| `setPosition(vec3)` | 世界坐标 |
| `setRange(float)` | 作用半径；衰减 `(1-d/range)²`，range 外熄灭。典型 5~10 |
| `setColor` / `setIntensity` | 强度典型 1.0~2.0 |

### 2.4 YalnSpotLight —— 聚光灯（探照灯/手电）

| 方法 | 说明 |
|---|---|
| `setPosition(vec3)` | 光源位置 |
| `setDirection(vec3)` | 照射方向（传播方向，自动归一化） |
| `setAngles(inner, outer)` | 内/外锥**半角**（度），自动保证 inner ≤ outer。典型 (18°, 30°) |
| `setRange(float)` | 作用距离。典型 10~15 |
| `setColor` / `setIntensity` | 强度典型 1.5~2.5 |

内锥内全亮，内→外锥平滑衰减（平方软化），外锥外熄灭。

聚光灯的 `position` 只表示光源位置，`direction` 才是光轴；两者在 GPU 打包结构中是独立字段，片段着色器用 `direction.xyz` 计算锥角。

## 3. 规则与限制

| 规则 | 说明 |
|---|---|
| 动态光源上限 **8** | 平行光 + 点光 + 聚光合计 ≤ 8；第 9 盏起被忽略并输出 stderr 警告 |
| 环境光上限 1 | 后加覆盖先加 |
| 所有权 | `addLight(unique_ptr)` 移交给场景；`scene.clear()` 会清空灯光 |
| 生效时机 | 修改光源属性**下一帧立即生效**（每帧重新打包 UBO），无需 rebuildScene |
| 与场景树的关系 | 光源不挂在节点上，用世界坐标直接定位（跟随场景树运动属 v2） |

**着色器一致性约定**：`YalnGPULight`（core/include/yalnlight.h）与 `shader.vert/frag` 中的
`struct Light` + UniformBufferObject 必须保持字段一致——改其一必须同步另一个，
否则表现为光照错乱或校验层报 std140 违规。

## 4. 示例场景的灯光布局（main.cpp 现状）

| 灯 | 类型 | 参数 | 位置 |
|---|---|---|---|
| 天光 | Ambient | 冷蓝 (0.58,0.65,0.78) × 0.55 | 全场 |
| 太阳 | Directional | 暖白 × 0.9，方向 (-0.45,-0.35,-0.9) | 无限远 |
| 路灯 ×2 | Point | 暖黄 × 1.3，range 8 | 东西路电线杆下 (0, 2.4, 1.62) / (7, 2.4, 1.62) |
| 风车探照灯 | Spot | 暖白 × 1.6，range 14，锥角 18°/30° | 风车杆顶 (-5.5, 9.5, 2.6) 斜向下 |

路灯配了高亮灯泡小球（`lampBulbMesh`）作为可视化锚点——光源本身不可见，
建议给每个点光/聚光配一个亮色小网格标出位置。

## 5. 调参指南

- **画面发灰/平** → 环境光太强：降到 0.3~0.4，让太阳的明暗对比立起来；
- **暗面死黑** → 环境光太弱或没加：先加环境光再调平行光；
- **点光"糊"** → range 太大 + 强度太高：先降 range 到刚好覆盖目标区域，再补强度；
- **聚光边缘有硬圈** → 内外锥角差太小：外锥比内锥大 10°~15° 最自然；
- **高光过艳/过淡** → 高光强度在 shader.frag 中是固定系数 `vec3(0.30,0.29,0.27)`，
  指数 32 控制光斑大小；调整请改 `shader.frag` 后重跑构建（glslc 自动编译）。

## 6. 常见问题

**Q：加了灯没效果？**
检查三处：① 是否调用了 `scene.addLight(...)`（构造对象不等于加进场景）；② 动态光源是否超过 8 盏（看 stderr 警告）；③ 光源位置是否在相机可见区域内。

**Q：点光源照亮范围是个圆形边界？**
这是 `(1-d/range)²` 衰减 + range 硬切除的设计行为（见设计说明 §3.3）。想要更柔和的边界就把 range 调大、强度调低。

**Q：想实现"灯光跟随节点移动"（比如挂在小车上）？**
v1 光源用世界坐标，需每帧手动 `light->setPosition(...)`。v2 的 `YalnLightNode` 会从节点世界矩阵自动取位（设计说明 §7）。
